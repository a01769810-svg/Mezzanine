# Cubos y base

Referencias del conjunto de cubos 3D y base azul de almacenamiento/posicionamiento.

Archivos:
- cubos_base_01_base_azul_vacia_vista_superior.jpeg
- cubos_base_02_cubo_verde_tapa_vista_superior.jpeg
- cubos_base_03_cubo_verde_vista_frontal.jpeg
- cubos_base_04_cubos_colores_en_base_vista_frontal.jpeg
- cubos_base_05_cubos_colores_en_base_vista_superior.jpeg

Componentes principales:
- Base azul rectangular tipo charola.
- Cubos de colores: rojo, verde, gris, amarillo, naranja, azul/cian y negro.
- Cada cubo tiene una tapa superior con relieve circular central y orificio.
- Algunos cubos muestran orificios en las esquinas.

Uso recomendado en RViz:
- Crear cubos como modelos simples parametrizables por color.
- Crear una base azul como contenedor estático.
- Mantener estos objetos separados del modelo general de la estación para poder simular pick/place.
